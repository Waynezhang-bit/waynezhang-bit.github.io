Privacy policy

Google data

The tool requests Google Drive, Docs and Sheets permissions. Full Drive permission can cover each file the Google account is allowed to access. The tool uses account information, file details and file contents as needed to find, create or edit files at the owner’s request.

AWS and Kiro

After authorisation, the tool stores OAuth credentials in an access-controlled file on the AWS workspace. When the owner runs a task in Kiro, file content needed for that task may appear in the tool output, stay in Kiro session records on AWS and be sent to Kiro’s model service to generate a response. The owner manages the records on AWS. The model service handles retention under its applicable terms.

Your choices

The owner can revoke access in Google Account connections and manage retained files and session records on AWS. Use and transfer of data received from Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements. For privacy queries, use the support contact on the app’s Google consent screen.

Website hosting

GitHub Pages hosts this information site. GitHub records visitor IP addresses for security purposes.

私隱政策

Google 資料

工具會要求 Google Drive、Docs 和 Sheets 權限。完整 Drive 權限可涵蓋該 Google 帳戶有權存取的檔案。工具按需要使用帳戶資料、檔案資料和內容，按擁有人要求查找、建立或修改檔案。

AWS 及 Kiro

完成授權後，工具把 OAuth 憑證儲存在 AWS 工作環境中受存取權限保護的檔案。擁有人在 Kiro 執行工作時，所需檔案內容可能出現在工具輸出、留存在 AWS 上的 Kiro 對話紀錄，並傳送至 Kiro 的模型服務以產生回覆。AWS 上的紀錄由擁有人管理。模型服務按適用條款處理資料保留。

撤回授權及管理資料

擁有人可在Google 帳戶的連接設定撤回授權，並在 AWS 上管理留存的檔案和對話紀錄。工具使用及傳輸從 Google API 取得的資料，須遵守Google API Services User Data Policy及其 Limited Use 要求。私隱查詢可透過應用程式在 Google 授權畫面所列的支援聯絡方式提出。

網站託管

這個說明網站由 GitHub Pages 託管。GitHub 為保安用途記錄訪客的 IP 位址。

隐私政策

Google 数据

工具会请求 Google Drive、Docs 和 Sheets 权限。完整 Drive 权限可涵盖该 Google 账号有权访问的文件。工具按需使用账号信息、文件信息和内容，按所有者要求查找、创建或修改文件。

AWS 及 Kiro

完成授权后，工具把 OAuth 凭据保存在 AWS 工作环境中受访问权限保护的文件。所有者在 Kiro 执行任务时，所需文件内容可能出现在工具输出、保存在 AWS 上的 Kiro 对话记录，并发送至 Kiro 的模型服务以生成回复。AWS 上的记录由所有者管理。模型服务按适用条款处理数据保留。

撤回授权及管理数据

所有者可在Google 账号的连接设置撤回授权，并在 AWS 上管理留存的文件和对话记录。工具使用和传输从 Google API 获取的数据，须遵守Google API Services User Data Policy及其 Limited Use 要求。隐私查询可通过应用在 Google 授权页面所列的支持联系方式提出。

网站托管

这个说明网站由 GitHub Pages 托管。GitHub 为安全用途记录访客的 IP 地址。
